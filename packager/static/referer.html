PebbleIDE Packager Referer

If you're seeing requests to your website with this page in their Referer header, someone is using a program they made with the PebbleIDE Packager to interact with your website.

The creator of the program set its package name to "". They can set this to anything they want, so it may or may not be meaningful.

The PebbleIDE Packager only turns projects into programs. It doesn't run them, and it can't tell you who is using a program or why.
